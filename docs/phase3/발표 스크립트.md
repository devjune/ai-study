# Koog 세미나 발표 스크립트 (15분)

슬라이드 14장 기준. 괄호는 목표 시간, 꺾쇠는 행동. 대본 합계는 약 12분, 나머지는 여유분.

---

## 1. 표지 (10초)

JetBrains가 만든 JVM 에이전트 프레임워크, Koog를 소개합니다.

## 2. 목차 (15초)

앞 4분은 Koog가 뭔지. 본론 6분은 미니 하네스를 다섯 단계로 키우며 설계를 봅니다. 데모 보고 마무리합니다.

## 3. 소개 (50초)

〈타임라인〉 에이전트 프레임워크는 파이썬이 먼저입니다. 2022년 LangChain.

JVM은 2023년 LangChain4j가 받았습니다. 스스로 "idiomatic Java"라고 소개합니다. Kotlin 네이티브는 아니라는 뜻입니다.

그 자리를 2025년 Koog가 채웠습니다. 작년 5월 1.0, stable 모듈은 1년 호환 보장입니다.

## 4. 왜 만들었나 (40초)

〈인용문〉 README 첫 줄입니다. 예측 가능, 장애 허용, 엔터프라이즈.

JetBrains가 Junie와 AI Assistant를 Kotlin으로 만들며 다듬은 방식을 공개한 겁니다.

공식 예제가 용도를 말해 줍니다. 문의 분류, 도구 호출, 외부 시스템 제어, 운영 모니터링. 운영을 겨냥합니다.

## 5. 기능 범위 (30초)

〈지도 전체〉 공식 문서 목차 전부입니다. 넓습니다.

오늘은 〈점선 행〉 전략 한 줄만 들어갑니다. 나머지는 자료로 공유합니다. 칩에 마우스를 올리면 한 줄 설명이 나옵니다.

## 6. 오늘 만들 것: 미니 하네스 (40초)

모델 호출만 하면 Spring AI로 충분합니다. 그 이상이 언제 필요한지 확인하러, 하네스를 다섯 단계로 키웁니다.

결론부터: 〈강조 박스〉 DSL이 아니라 그래프가 핵심입니다. 단계마다 이 말을 확인합니다.

## 7. 1단계: 기본 에이전트 (40초)

〈코드〉 다섯 줄이면 REPL이 됩니다.

핵심은 promptExecutor. Spring AI 브리지가 만든 빈이고, 모델 설정은 기존 properties 그대로입니다. 기존 프로젝트 위에 그냥 얹습니다.

## 8. 2단계: 노드와 엣지 (50초)

흐름은 그래프로 적습니다. 〈✕ 줄〉 그냥 이으면 컴파일 거절. 출력과 입력 타입이 맞아야 엣지가 붙습니다.

실행해 봐야 알 연결 오류를 컴파일러가 먼저 잡습니다.

## 9. 2단계: 조건 엣지 (50초)

분기는 if문이 아니라 엣지 선언입니다. 규칙 셋: 적은 순서대로 검사, 먼저 맞은 하나만, true 엣지가 else 자리.

단, 분기 누락은 컴파일러가 모릅니다. when과 다른 점이고, 오늘의 트레이드오프입니다.

## 10. 3단계: 히스토리 (40초)

〈코드〉 polish에 넘긴 건 새 질문 한 줄인데 답이 15입니다. 두 노드가 같은 대화 기록 위에서 돕니다. 값이 아니라 대화가 흐릅니다.

대신 기록이 쌓입니다. 그래서 압축 노드가 따로 있습니다.

## 11. 4단계: 반복 상한 (40초)

〈예외 블록〉 탈출 조건을 망가뜨리면 무한 루프 대신 예외입니다.

상한은 루프가 아니라 에이전트 설정에 있고, 안 적으면 기본값. 빠뜨릴 자리가 없습니다. 단위는 그래프 전체 걸음 수입니다.

## 12. 5단계: 시각화 (30초)

〈다이어그램〉 그 라우팅 전략에 asMermaidDiagram() 한 번. 코드에서 나온 그림이라 코드가 바뀌면 그림도 바뀝니다.

타입 검사, 상한, 이 그림. 전부 그래프가 값이라서 얻는 겁니다.

## 13. Demo (2분)

〈미리 띄운 REPL로 전환〉

입력 1: "내일 일정 알려줘" → 캘린더 도구 왕복.

입력 2: "판교 사투리 11로 바꿔 줘: 내일 회식 오세요" → SKILL.md를 읽고 변환. 〈출력을 잠시 읽게 둔다〉

한 마디: 4B 모델은 도구 둘을 섞으면 헛짚어서, 역할별 에이전트로 갈랐습니다. 작은 모델일수록 프롬프트보다 구조입니다.

## 14. 적용하며 확인한 것 (3분, 질의 포함)

〈빈칸 장〉 직접 확인한 것 2~3개를 말한다.

(발표 전에 채울 것. 후보: 타입 불일치 검출 / 엣지 순서에 따른 분기 역전 / 분기 누락은 컴파일러가 못 잡음 / 도구 파라미터 추가 시 스키마 자동 반영)

질문 받고 마무리. 자료와 코드는 공유.
